**Disposition: invalid measurement; no adoption or regression inference.** The 63 author trials completed, but subsequent independent semantic audits invalidated their comparison. The candidate was not changed or retrospectively rescored. Independently authored V3 tasks replace this cohort.

## Invalidations

- **V2-02:** undeclared literal/variance constraints rejected allowed unknown-value representations in all nine artifacts.
- **V2-04:** homemade name extraction included an `aria-hidden` arrow that native Chrome AX correctly excluded.
- **V2-03:** undeclared blank-timestamp and exhausted-response refresh requirements rejected otherwise permitted behavior.
- **Text scaling:** all 54 browser tasks ran text-200 at 320 pixels, conflicting with the frozen 1440-pixel declaration. Actual font doubling was measured; fixture parity was nevertheless invalid.
- **Paired review:** a single-resource citation contract could not represent the required two-artifact evidence. All 42 comparisons failed twice; there were no valid pair votes.
- **Runtime evidence:** the original consumer could accept source/rendered-only evidence as runtime proof. The corrected consumer requires a measured/behavioral record containing an actual observation.

Original review recorded 41 assertion failures and 94 uncertainties. Six assertion disagreements were adjudicated; this did not repair invalid measurement. Genuine failures also occurred, including 327-pixel horizontal overflow in a 320-pixel text-200 context. Invalid constraints do not justify waiving every failure.

## Measurement repair, not candidate tuning

The replacement infrastructure uses native AX names, semantic-equivalent controls, explicit context dimensions, pre-document service/print instrumentation, named-state images, typed runtime evidence, paired citation arrays, kernel ownership leases, and actual SDK text/image inclusion checks. Reviewer projections preserve measurement multiplicities, raw hashes, every mismatch and unknown, while removing redundant aggregates and repeated screenshot base64. Report projection bytes directly; different cohorts cannot establish causal token savings.

The first development V3 validation had nine mismatches and is retained as failed evidence. Its historical evaluator was not independently snapshotted before corrections, limiting byte-for-byte replay. The successful replacement validator snapshots all sources before import and execution. Full raw evidence and its bounded archive retention are recorded in the final pilot report.
