## Rule and resource decision

The unchanged rule requires all 21 candidate successes, at least 14 wins against current with at most three losses, wins exceeding losses in at least five briefs, no per-brief success deficit against no-skill, no more baseline losses than wins, and auditable isolation/fixture/context comparisons. Candidate had one verified success, one current win, one brief with more wins than losses, baseline deficits, and missing packet audits. **The declared disposition is inconclusive; adoption is not authorized by this pilot.**

No optional assets, library, or runtime scripts were added to the payload. Three selective data-reference loads demonstrate recurring use in this task class, not a proven benefit or a need for executable helpers. The new scripts and fixtures are repository-only measurement resources, justified by recurring oracle, isolation, and context-audit failures. They do not change installation or agent permissions. Any future guidance revision needs independently new cases and a new freeze; these released cases are now exposed.

## Limits and retention

The namespace/tool boundary was exercised, including traversal/symlink denials, overlapping reads, real native controls, all eight browser actions, deadlines, hard-kill trace retention, and kernel-lease exclusion. Provider networking shares the host network; no OS-level destination firewall is claimed. Chrome's inner sandbox was disabled only inside mandatory outer bubblewrap. Fonts/runtime identities were checked, but shared host infrastructure and vendor internals are not immutable VM images.

Model reviewers share a model family and may have correlated judgments. The pilot is small and synthetic; it does not cover every production framework, assistive technology, physical print workflow, or user population. Print evidence covers the API request and print CSS, not OS dialogs or pagination. Text scaling preserves later inline changes by value/priority ownership; identical writes cannot be distinguished.

All preflight failures remain documented, including stale SDK lookup, unsupported bubblewrap flag, AppArmor sandbox failure, socket-path length, argument/permission forwarding, native date input, event settling, initial oracle mismatches, zero-font scaling, and inline-style ownership. The first V3 development validation had nine mismatches; its historical evaluator was not separately snapshotted before correction. Successful validation snapshots sources before import. Controls establish their declared scope, not universal oracle correctness.

Full evidence is retained in two owned, checksummed archives listed in the JSON ledger: invalid V2/preflights/controls and completed V3/raw review. **Expiry: 2026-11-01 23:41:36.493 UTC**, one day after blind-review completion. Archives are verified against source bytes before owned scratch retirement; shared caches and user services are preserved. Compact reports remain in this repository. Final structural/installation checks cannot repair the inconclusive outcome.
